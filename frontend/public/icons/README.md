# Selada icons

Original local SVG icons on a 24 x 24 grid, with 1.75px rounded strokes.
Each SVG is usable independently; sprite.svg contains the matching symbols used by AppIcon.vue.
Keep the standalone asset and sprite symbol in sync when editing an icon.

Usage: <AppIcon name="search" class="w-4 h-4 text-slate-500" />
Icons inherit currentColor. Decorative icons are hidden from assistive technology;
use title for a meaningful standalone icon, and label icon-only buttons on the button itself.
No remote icon service or package is required.
